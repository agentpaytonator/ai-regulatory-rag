# This repository contains the source code and files for the AI Engineering Project.

## What This Project Does
This project is a Python-based AI engineering project that demonstrates fundamental concepts and practices for building, testing, and running Python applications.

## Python version
Python 3.14

## Setup .venv
### Create the virtual environment
Create a Python virtual environment named '.venv'.
In GitBash, enter the command: 'python -m venv .venv'.
### Clone the repository.
In GitBash, enter the commands 'cd ~/Desktop', then 'pwd', then git clone 'https://github.com/username/repository-name.git'.
### Activate the virtual environment
In GitBash, change to the project directory, then enter the commands: 'python -m venv .venv', then 'source .venv/Scripts/activate'.

## Install requirements
Create a text file called 'requirements.txt'.
In GitBash, enter the commands 'pip install -r requirements.txt', then 'python -m pip freeze > requirements.txt', then 'python -m pytest'.

## Run the Program
From the project root directory, run:
In GitBash, enter the command 'python src/hello.py'.

## Run the tests
In GitBash, enter the command 'python -m pytest'.
